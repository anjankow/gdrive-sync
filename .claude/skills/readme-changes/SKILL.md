# README changes

Do not modify `README.md` unless one of these is true:

- The user explicitly asks for a README change.
- The README has become outdated: something it states is no longer true after a change
  (for example a build dependency, a command, a setup step or a described behavior).

When the README is outdated, change only the statements that became wrong. Do not add
descriptions of new features, fixes or internals.

The README is not a changelog: it does not need to mention everything that was worked on.
